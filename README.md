# Клиентские демонстрации: GitHub → GitHub Actions → GitHub Pages

Выбрано пользователем 26.10.2026. Организация PLUR-Peas, планируемый публичный репозиторий client-previews. REG.RU остаётся без изменений. GitHub Pages не обеспечивает размещение на серверах РФ; пользователь выбрал попробовать этот вариант для показа заказчику.

## Одноразовая настройка

1. Войти в GitHub в открытой вкладке встроенного браузера.
2. Создать публичный репозиторий client-previews в организации PLUR-Peas. Подключённый GitHub API умеет загружать файлы, но не создавать репозитории или включать Pages, поэтому эти операции выполняются через браузер.
3. Загрузить текущие файлы этой папки (не local-projects.json, не ключи и не каталоги других проектов). Git уже инициализирован локально, ветка main.
4. В Settings → Pages → Build and deployment выбрать Source: GitHub Actions.
5. Отправить коммит в main или запустить workflow Publish client previews вручную. Дождаться успешной публикации и проверки реального адреса без авторизации.

На GitHub Free Pages доступен для публичных репозиториев, исходники общедоступны. Сайт будет по техническому адресу github.io без покупки домена. Фактический URL берётся из результата deployment, заранее готовность адреса не утверждается.

## Каждая публикация

После одобрения изменений выполнить:

```powershell
.\Publish.ps1 -Message 'Update Vconsalte'
```

Скрипт берёт актуальный локальный dist по local-projects.json, проверяет ресурсы, делает коммит и push в main. Не выполняет force push. В облаке workflow сначала проверяет ресурсы и синтаксис JavaScript, затем публикует только public/, после чего без cookies сверяет SHA256 каждого публичного файла. Если проверка или деплой неуспешны, workflow сообщает ошибку. Автоматического отката после HTTP-ошибки нет; для отката сделать git revert и дождаться нового workflow.

Для нового проекта добавить slug и путь готовой статики в local-projects.json; этот файл не отправляется в GitHub. Проект появится в public/<slug>/ и получит адрес /<slug>/ относительно сайта Pages. Первым подготовлен /vconsalte/.
